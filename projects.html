cstrack — Counter-Strike Match Tracker

Python · standard library only · 2026

A zero-dependency command-line tool for logging Counter-Strike matches. It records each match — map, kills, deaths, rounds won and lost — to a JSON file and reports aggregate stats like overall K/D and win rate. Built around an add / list / stats subcommand interface using only argparse and json. A ground-up rewrite of an earlier prototype (CSGOProject), rebuilt as a proper scriptable CLI after learning argparse.

WriterDeck — Journaling CLI

Python · standard library only · 2026

A terminal journaling tool. Write an entry across as many lines as you want, type END on its own line to finish, and it's appended to a single running log with your name, a title, and a timestamp — so the whole history reads straight through in one file. Named after the SEELE monoliths from Neon Genesis Evangelion.
